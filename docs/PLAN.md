# 《汇市物语》（暂定名）开发计划

> 一款原创的外汇模拟交易科普小游戏。参考了 B 站「FX 简单！」的品类思路，但代码、文案、美术全部从零原创，并在交易机制与玩法深度上做出差异化。
>
> 状态：**P0（M1 核心循环）已实现并通过自测** ｜ 更新日期：2026-09-29

---

## 1. 项目概述

**一句话定位**：用 5 分钟学会「做多、做空、杠杆、止损」，在模拟盘里亲历真实外汇史上的经典时刻。

**核心循环**：

```
看行情 → 判断方向 → 设置仓位/杠杆/止盈止损 → 开仓
   ↑                                        ↓
 复盘统计 ← 结算/爆仓 ← 行情跳动（模拟或历史回放）
```

**设计原则**：

1. 纯模拟，永不接入真实资金，界面常驻「模拟盘」标识。
2. 教育优先：每个机制（点差、爆仓、隔夜利息）都对应真实市场概念，配通俗解释。
3. 轻量可玩：单页面 H5，手机优先，加载秒开，无需注册。
4. **60 秒上手**：新玩家进页 60 秒内完成第一笔交易并看到盈亏结果；学习放进「做」里，不做前置文字墙。
5. **渐进式解锁**：新手默认只看到「买涨 / 买跌 / 下单」，杠杆、挂单、高波动货币对随等级逐步开放，杜绝「开局选 100× 秒爆仓」。
6. **即时爽感**：每笔交易都有动效与数字反馈（最小包 P0 就做），第一局内必遇一次事件高光时刻。

**目标用户**：对投资感兴趣但没实盘经验的新手；想回顾外汇大事件的爱好者。

**与「FX 简单！」的差异化**（它没做、我们做）：

| 差异点 | 说明 |
|---|---|
| 止盈 / 止损单 | 原版只能手动平仓；SL/TP 是真实交易最重要的风控工具，也是最好的风险教育 |
| 交易成本模拟 | bid/ask 点差、滑点、隔夜利息（swap），让玩家理解「交易有成本」 |
| 挂单系统 | 限价单 / 突破单，玩法从「盯盘手点」升级为策略布局 |
| 新闻事件驱动 | 模拟行情中随机插入「非农」「央行议息」等事件冲击，取代纯随机漫步 |
| 交易复盘页 | 胜率、盈亏比、最大回撤、权益曲线 |
| 周挑战模式 | 固定随机种子，所有玩家同一局行情，本地结算、晒成绩卡对比，无需服务器 |

## 2. 原创与合规边界

**必须做的（红线）**：

- 代码从零手写，不复制参考项目的任何源码、样式、HTML 结构。
- 全部文案原创：游戏名、教程话术、UI 文案、彩蛋剧情一律重写。
- 美术原创：吉祥物用自绘 SVG 或免费可商用素材（**不用任何动漫角色图片**）。
- 不接入真实资金、不接充值/抽奖/开箱，无任何变相赌博机制。
- 界面与教程中持续声明「模拟游戏，不构成投资建议」。

**可以放心用的**：

- 交易机制与规则（杠杆、保证金、爆仓线等是通用金融概念，不受版权保护）。
- 公开免费行情数据：Frankfurter（ECB 日度汇率）、Stooq、Binance K 线（加密货币）等开放接口。

**发布合规**：托管 GitHub Pages 无需备案；若用自有大陆域名 + 服务器则需 ICP 备案。纯免费、无内购的个人小游戏不涉及版号问题（若日后上 B 站玩具平台投稿，按平台规则提交即可）。

## 3. 功能规划（三期）

### P0 — MVP：核心交易循环（先让游戏「转起来」）

> 为落实「易上手 + 好玩」，P0 新增了动效包、序章事件、点词解释、等级成长线等小项（各约半天量级）。若排期吃紧，砍的优先级从低到高：PWA → 等级 UI（退化为隐形解锁）→ 动效包；**交互式引导第一单和新手保护期不可砍**——它们就是「易上手」本身。

- [x] 虚拟账户：初始 $10,000，权益 / 可用余额 / 浮动盈亏 / 已用保证金
- [x] 5 个货币对（EUR/USD、GBP/USD、USD/JPY、AUD/USD、USD/CHF），**开局只解锁 EUR/USD**，其余随等级解锁
- [x] 做多 / 做空，保证金开仓，80% 爆仓线 + 爆仓弹窗；杠杆新手封顶 10×，等级解锁至 100×
- [x] **止盈 / 止损单**（核心差异点），新手默认「自动保护」：开仓即挂温和的 SL/TP，避免裸单
- [x] 模拟行情：种子随机数 + 趋势漂移 + 偶发冲击，每 1.5s 一根 K 线；**新手保护期**——前几笔交易使用低波动、温和趋势的种子，保证首次体验大概率正反馈
- [x] Canvas 手绘 K 线图 + 当前价线，支持缩放拖动
- [x] **交互式引导第一单**（替代原「5 步教程」：高亮引导玩家完成「买涨 → 止盈结算」，话术原创、边做边学）
- [x] **等级成长线（最简版）**：按交易笔数 / 盈利里程碑升级，解锁货币对、更高杠杆与进阶面板（新手/进阶双模式 UI）；成就系统仍在 P1
- [x] **最小动效包**：盈亏数字跳动、平仓结算弹出、爆仓红屏震动（音效仍留 P2）
- [x] **序章脚本事件 ×1**：如「央行意外降息」行情跳变 + 事件卡片，保证第一局内必遇一次高光（P1 事件系统是它的泛化）
- [x] **术语点词解释**：面板中的术语点击即弹一句话解释 + 小例子（P1 完整术语表的前置最小版）
- [x] localStorage 存档 + 读档；「重新开始」
- [x] 移动端自适应布局 + PWA（manifest + Service Worker）

### P1 — 深度：真实感与教育性

- [x] **经典战役模式**（首批 4 场，每场配原创历史解说）——全游戏最大的「哇」点，P1 最优先：
  1. 1992 黑色星期三 —— 索罗斯狙击英镑（GBP/USD）
  2. 2015 瑞郎脱钩黑天鹅（EUR/CHF）
  3. 2016 英国脱欧公投（GBP/USD）
  4. 2024 年 8 月日元套息平仓风暴（USD/JPY）
- [ ] 点差 / 滑点 / 隔夜利息，成本在开平仓明细中展示
- [ ] 挂单：限价单、突破单、（可选）追踪止损
- [ ] 真实行情回放：接入 Frankfurter 拉取近 2 年日度汇率，逐日回放
- [ ] 新闻事件系统：模拟模式随机触发「非农 / 议息 / CPI」事件，行情跳变 + 事件卡片（将 P0 序章事件泛化成通用系统）
- [ ] 复盘统计页：胜率、盈亏比、最大回撤、权益曲线
- [x] 龙虎榜：注册代号 + SQLite 服务端排行（P1 计划外新增，2026-09-29 完成）
- [ ] 成就系统（10–15 枚）：「首次做空盈利」「黑天鹅中存活」「连续 10 笔带止损」等
- [ ] 完整术语表：补全条目与分类浏览（P0 已有点词解释的最小版）

### P2 — 留存与社交

- [ ] 周挑战：固定种子 + 固定历史片段，全玩家同一行情；结束生成成绩卡图片（Canvas 导出）供分享
- [ ] 更多战役扩充（1997 亚洲金融危机、2020 美元荒等）
- [ ] 多存档位 + 存档导出/导入 JSON
- [ ] 音效与开仓/爆仓动效（可关）
- [ ] 加密货币交易区（Binance K 线接口，模拟交易）
- [ ] 中英双语（i18n）
- [ ] 彩蛋系统（原创剧情，参考「一次性救援」的思路但完全重写）

## 4. 技术方案

| 项 | 选型 | 理由 |
|---|---|---|
| 整体 | 原生 JS（ESM）+ Canvas，**无框架、无构建** | 参考项目证明了该规模下单文件原生完全够用；零依赖 = 永不过期、随便部署 |
| 目录 | `index.html / styles.css / src/`（按模块拆 ESM 文件） | 比单文件好维护，仍是纯静态 |
| 随机数 | 种子化 PRNG（mulberry32 等） | 模拟行情可复现，周挑战公平的前提 |
| 图表 | Canvas 自绘（蜡烛图 + 十字光标 + 缩放） | 不引图表库，控制体积与手感 |
| 行情数据 | 数据源抽象层 `DataSource` 接口 | 见下表，可切换/可缓存 |
| 存储 | localStorage（JSON 存档），P2 升级 IndexedDB | 简单够用 |
| 部署 | GitHub Pages（或自有静态托管） | 纯静态，推完即上线 |

**数据源对比**：

| 数据源 | 内容 | 粒度 | 费用/Key | 用途 |
|---|---|---|---|---|
| Frankfurter | 法币汇率（ECB） | 日线 | 免费/无需 Key | 真实回放、经典战役 |
| Stooq | 外汇/股指/商品 | 日线+部分分钟 | 免费 | 备胎数据源 |
| Binance API | 加密货币 | K 线全粒度 | 免费/无需 Key | P2 加密区 |
| 本地模拟 | 种子随机 | 任意 | — | 模拟模式、周挑战 |

**模块划分（src/）**：`engine/`（账户、持仓、订单撮合、爆仓）、`market/`（数据源、模拟行情、事件系统）、`chart/`（绘制）、`ui/`（面板、弹窗、教程）、`core/`（存档、PRNG、i18n）。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 免费行情接口限流/失效 | 多源抽象层 + 本地缓存最近数据；模拟模式完全不依赖网络 |
| 教育内容失准（利率、事件细节） | 战役解说标注资料来源；数值表以真实市场常识为准绳 |
| 被误认为投资工具 | 首屏 + 教程 + 每个下单面板常驻「模拟游戏」声明；不出现任何券商品牌 |
| 素材版权 | 只用自绘/CC0 素材，建立素材清单（来源+许可证） |
| 范围膨胀 | 严格按 P0→P1→P2 顺序，P0 未验收不开工 P1 |
